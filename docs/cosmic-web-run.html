Linear growth test

Large-scale power divided by linear theory, P/Plin for k < 0.012. A correct integrator stays at 1 until those scales go nonlinear. The paired runs average this seed with its sign-flipped twin, which cancels this realization's second-order wobble.

Power spectrum by epoch

Dimensionless power Δ²(k) = k²P/2π measured from the particles (solid) against linear theory (dashed). Small scales break away first; where Δ² crosses 1 is knl.

How this was run

6144² = 37.7 million particles in a periodic box of side 2000, Einstein–de Sitter expansion from a = 0.02 to 1 with linear growth D = a. Zel'dovich initial conditions from P₀(k) ∝ k⁻¹ e^−(kR)². Gravity is a 2048² particle-mesh FFT solve of the 2D Poisson equation on an RTX 5080, integrated with a comoving KDK leapfrog (Quinn et al. 1997) over 959 steps, about 90 s of wall time. Analysis ran offline on the Ryzen: CIC + FFT power spectrum, periodic friends-of-friends halos, Press–Schechter with a 2D top-hat collapse threshold, and a Sheth–Tormen fit. This is a 2D model universe: the methods are those of lab codes, the physics is a planar toy.
